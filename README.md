# Приложение для управления семинарами

Этот проект представляет собой веб-приложение для управления семинарами, построенное с использованием React, TypeScript, и интегрированное с имитацией API через `json-server`. Пользователи могут просматривать, редактировать и удалять данные семинаров, а также переключаться между различными режимами отображения списка семинаров.


## Используемые технологии

- **Vite** 
- **React**
- **TypeScript** 
- **json-server**
- **CSS/Sass**
- **React Modal**
## Установка

### Шаг 1: Клонируйте репозиторий
---
Клонируйте репозиторий:
```bash
git clone <url-репозитория>
```
### Шаг 2: Установите зависимости
---
```bash
cd <папка-проекта>
npm install
```
### Шаг 3: Запустите сервер разработки
---

**Запустите react приложение и API-сервер json-server:**
```bash
npm start
```
